# livariaUnipar
Livraria Spring

Objetivo: Implementar a entidade Autor e seu relacionamento com a entidade Livro já criada, utilizando o Spring Boot deverá criar um CRUD completo para a gestão de autores e livros, e um endpoint adicional que traga todos os autores juntamente com os livros que eles escreveram.

Endpoints CRUD para Autor e Livro:

GET: Buscar todos os autores.

GET: Buscar um autor específico pelo id.

POST: Criar um novo autor.

PUT: Editar informações de um autor existente.

DELETE: Deletar um autor pelo id.

GET: Buscar todos os livros ou um livro específico pelo id.

GET: Criar um endpoint que retorne todos os autores e, para cada autor, traga todos os livros que ele escreveu.
